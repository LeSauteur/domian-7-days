# 7 дней эффективной работы — MVP

Статическое mobile-first приложение для сети агентств недвижимости «Домиан». Содержание всей недели адаптировано из глав 6–19 книги «7 дней эффективной работы 2.0».

## Реализовано

- стартовая страница и навигация по семи дням;
- полноценные экраны ПН–ВС в едином data-driven шаблоне;
- action-first экран дня: миссия, прогресс и checklist видны в первом mobile viewport;
- чек-лист с прогрессом, сохранением в `localStorage` и защищённым сбросом;
- копирование готового сообщения с inline-уведомлением;
- независимый прогресс каждого дня и последовательные переходы Previous / Next;
- постоянное completed-состояние с переходом к следующему дню или к неделе после воскресенья;
- закрытые по умолчанию accordion-блоки «Подробнее»;
- preview базы знаний;
- облегчённый воскресный сценарий: закрытие недели, восстановление и ненавязчивые связи.

## Запуск

Можно открыть `index.html` двойным кликом. Для запуска через локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Основные файлы

- `index.html` — оболочка приложения;
- `css/styles.css` — адаптивный интерфейс;
- `data/days.js` — метаданные недели и контент всех семи дней;
- `js/app.js` — общий рендер дней, навигация и интерактивная логика.
