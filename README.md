# DOMIAN 7 DAYS — календарный mobile-прототип

Статическое mobile-first приложение для сети агентств недвижимости «Домиан». Семь ежедневных сценариев для руководителя адаптированы из книги «7 дней эффективной работы 2.0».

## Реализовано

- главная сразу открывает миссию текущего дня по времени `Europe/Moscow`;
- компактный календарь ПН–ВС со статусами дня и отдельной отметкой «Сегодня»;
- полноценные экраны ПН–ВС в едином data-driven шаблоне;
- action-first экран дня: миссия, прогресс и checklist видны в первом mobile viewport;
- у каждого действия видны пояснение и отдельный раскрываемый критерий «Когда отмечать?»;
- семь готовых сообщений агентам, копируемые рабочие шаблоны и общая карточка координации;
- видимые ссылки на главы/страницы и полная 36-страничная книга 2.0;
- календарное хранение прогресса по дате и задаче в `localStorage`;
- прошлые и будущие дни доступны для просмотра, но редактируется только сегодняшний;
- состояния «Не начато», «В работе», «Выполнено», «Не завершено», «Предстоит» и «До начала участия»;
- честный недельный итог: победа только при 7/7, без блокировки после пропуска;
- защищённый сброс только сегодняшнего прогресса с подтверждением и отменой;
- копирование готового сообщения с inline-уведомлением;
- отдельный визуальный объект среды «Точка остановки / движение объекта»;
- закрытые по умолчанию accordion-блоки «Подробнее»;
- воскресный сценарий без обязательных знакомств: итоги, шаг понедельника, границы связи и состоявшийся отдых.

## Календарные допущения v1

- неделя считается с понедельника по воскресенье в часовом поясе Москвы;
- при первом входе посреди недели предыдущие дни получают нейтральный статус «До начала участия»;
- участие в полном недельном результате начинается со следующего понедельника; сегодняшняя миссия доступна сразу;
- новый понедельник создаёт новый календарный период, а записи предыдущих дат сохраняются;
- данные хранятся только в текущем браузере и не синхронизируются между устройствами.

Редакционный пакет этапа A использует ключ `domian:calendar:v3`. При первом открытии датированное состояние `domian:calendar:v2` копируется в совместимую схему: даты с прежними отметками продолжают показывать прежний список, а галочки не присваиваются новым по смыслу действиям. Исходный ключ v2 не удаляется. Ещё более старые недатированные ключи вида `domian:monday:checklist:v1` также остаются без изменений и не переносятся автоматически.

## Инструменты руководителя

Через ссылку в шапке дня или значок книги открывается `#tools`:

- «Три опоры роста»: клиенты, объекты, ресурсы; после выбора — вопросы и первый шаг для проверки гипотезы.
- Четыре модели: деньги, клиенты, бюджет, команда. Раскрывающиеся карточки с действиями и личными заметками.
- Недельная рефлексия 80/20: что дало результат и что убрать. Доступна также рядом с итогом недели; прошлые записи выбираются на странице инструментов.

Основа — идеи книги Гари Келлера и соавторов «Как стать миллионером, продавая недвижимость»: с. 33–35, 93–94, 126–177 (печатная нумерация). Вопросы адаптированы для офиса Домиан. Финансовые нормативы и таблицы книги не переносились; сам PDF Келлера не публикуется.

Заметки хранятся отдельно в `domian:leader-tools:v1`, не влияют на миссии и не удаляются при сбросе чек-листа. Блоки недели, задания и их версии не менялись. Цветовая тема выбранного дня распространяется на hero и спокойные поверхности; зелёный остаётся цветом выполнения.

Данные и интерфейс новых инструментов: `data/leader-tools.js` и `js/leader-tools.js`. Сервер и сборка не требуются.

## Запуск

Можно открыть `index.html` двойным кликом. Для запуска через локальный сервер из папки проекта:

```powershell
python -m http.server 8000
```

Затем открыть `http://localhost:8000`.

## Основные файлы

Для FRchat опубликован `data/days.json`: темы семи дней, действующая версия контента и действия со стабильными идентификаторами. Личные отметки и заметки в файл не входят. После изменения `data/days.js` обновить экспорт командой `node scripts/export-days.js`. Проверки: `node scripts/export-days.js --check`, `node tests/days-export.test.js`, `node tests/calendar.test.js`. FRchat читает этот файл без авторизации и сопоставляет отметки только при совпадении версии контента и сегодняшней даты.

- `index.html` — оболочка приложения;
- `css/styles.css` — адаптивный интерфейс;
- `data/days.js` — метаданные недели и контент всех семи дней;
- `js/calendar.js` — московская дата, календарные статусы и недельный результат;
- `js/app.js` — общий ежедневный экран, навигация и интерактивная логика;
- `assets/docs/domian-7-days-effective-work-v2.pdf` — полная книга «7 дней эффективной работы 2.0»;
- `tests/calendar.test.js` — проверки календарных границ и итогов недели.

## Сознательно отложено

Этап B (справочник по рабочим ситуациям) и этап C (согласованная ротация акцентов по неделям) не реализованы. Отдельное продуктовое решение всё ещё требуется для дня без подходящих клиентов, эксклюзивов или показов: автозачёта и статуса «Не применимо» сейчас нет. Backend, аккаунты, синхронизация и аналитика не входят в текущую модель.
